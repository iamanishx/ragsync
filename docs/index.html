Discord RAG Bot Skii
Multi-Provider AI Assistant

A production-ready Discord bot enabling users to chat about anything they want using any AI provider (OpenAI, Claude, Gemini, Groq, OpenRouter) with personal API keys. Chat memory is preserved across all models, ensuring seamless conversations even when switching between AI providers.

Key Features

🔐

SaaS-Ready

Users provide their own API keys via secure web portal. No admin API costs or key sharing.

🧠

Multi-Provider AI

Support for 5+ AI providers: OpenAI, Claude, Gemini, Groq, OpenRouter with latest models.

📚

Persistent Memory

Engage in dynamic conversations with memory retention, allowing seamless context switching and continuity across interactions, all within a user-friendly Discord interface.

🔄

Flexible Setup

Personal or server-wide configurations with user preference switching between API sources.

🐳

One-Command Deploy

Docker deployment with Redis + Qdrant. Run locally or deploy to Railway, Render, etc.

⚡

Production Ready

Rate limiting, health checks, encrypted storage, auto-restart, and comprehensive error handling.

System Architecture

Modern architecture with Discord.js, Redis caching, Qdrant vector database, and multi-provider AI integration.

Quick Setup

1

Clone & Setup

Clone the repository and configure environment variables with your Discord bot token.

2

Deploy Services

Use Docker Compose to spin up Redis, Qdrant, and the bot application.

3

Configure AI

Users setup their own API keys via secure web portal with provider selection.
